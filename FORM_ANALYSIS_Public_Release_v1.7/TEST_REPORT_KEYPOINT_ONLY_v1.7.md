# v1.7 キーポイント時間平滑化のみ — テスト報告

- 計算用動画フレームの各MediaPipeランドマーク（x/y）に対してだけ、選択された1〜5フレームの移動平均を1回実行。
- 派生量（重心、身体中心、速度、加速度、床反力、エネルギー、リリース距離、回旋角度・角速度）には追加の時系列移動平均／中央値フィルタを適用しない。
- キーポイント欠測中心は欠測のままとする。接地状態は連続サンプルによる状態判定（フィルタではない）。
- Node.jsの模擬30フレーム×設定1〜5で合計6,700件の数値を比較。キーポイントだけ1回平滑化してから平滑化なしで算出した結果と全指標が一致（誤差1e-7未満）。中心欠測非補完、元データ非破壊、脚別合力と成分の同一フレーム一致、捻転角度／角速度の差分一致、JavaScript構文を確認。
